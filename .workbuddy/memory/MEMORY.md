# 项目长期约定（Moxie）

## 工程范围
- 后续所有工程化建设、演进、测试与文档收口**仅覆盖三个在线项目**：`/server`、`/client`、`/admin`。
- 离线桌面端及其构建、E2E、打包链路（`web/`、`e2e/`、`src/` 桌面运行代码、`build*.bat`、`start*.bat`、`stop*.bat` 等）为**存量资产**：保持现有代码存在即可，不再新增功能、不再纳入后续工程改造或质量门禁扩展。
- 明确跳过：i18n、站点地图。
- 当前 CI 中的 `e2e-desktop` job 仅作历史存量保留；后续不为其新增用例或能力，除非用户明确要求移除。

## 已确立的协作口径
- 中文沟通，简洁直接；优先给完整可运行代码/配置，少写解释。
- 用户偏好简洁、熟悉、浏览器式 UI 交互；样式问题通过截图迭代。
- Skill 体系以 `config/skills_catalog.json` 为唯一事实源，`scripts/check_skills.py` 做硬校验；server/client/admin 三端目录与文档变更必须同步。
- 改动长期保留在工作区，用户尚未要求提交 git；不要擅自提交。
