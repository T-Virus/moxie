- 后端：`server/.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider`（约 4 分钟，296 用例 + 3 skip）
- 前端：`npm run typecheck` + `npm run build`（client / admin 均通过）
- 真实 HTTP 冒烟：临时 uvicorn（127.0.0.1:18080，SQLite + Redis 关闭 + mock 支付）跑通 24 项端到端检查（注册/登录/订阅/额度/写作运行/后台看板/预设/封禁/License/前端产物）

### 修复的真实 BUG（回归，来自上一次提交）
1. `app/agents/engine.py`：`_run_segmented_node` / `_run_chaptered_node` 同时用位置参数和关键字传 `session`，20+ 用例 TypeError。
2. `app/prompts/review.py`：`run_review()` 缺少 `base_url` 形参，单章体检 runner 调用即 NameError/TypeError。
3. `app/config.py`：`email_verification_required` 默认 True 后，部分自建 Settings 的测试未关闭，注册不返回 token。
4. `client/src/services/presets.ts`：路径写成 `/v1/presets`，而 `API_BASE` 已含 `/v1` → 实际 `/v1/v1/presets` 全部 404，后台预设维护对 C 端完全不生效（静默回落本地常量）。
5. `admin/src/views/Invoices.vue`：只取前 50 条本地分页；开具/作废走 `POST /admin/invoices/{id}` 仅改 DB，未走 `/issue`、`/void` 渠道端点。
6. `app/api/admin.py` 离线包上传：`pkg.id` 在 `db.flush()` 前为 None，导致同平台历史版本更新条件错误，且审计日志在 commit 之后写入而丢失。
7. `app/api/admin.py` 额度调整：`used += quantity` 与后台表单「正数增加额度」语义相反，补偿变扣减；改为 `used -= quantity`。
8. `app/services/orders.py`：渠道退款回调状态 `refunded` 未归一为 `succeeded`，成功退款永远停在 pending。

### 安全加固
- 新增 `Settings.is_production`（白名单：仅 dev/test/testing/local 为非生产），替换散落的 `env in ("prod","production")` / `env != "production"`，修复 ENV=prod 时验证链接仍回显。
- `deps.get_auth`：校验 RefreshSession 归属 account_id 与过期时间。
- `orders.create_upgrade_order`：过期/非服务中订阅禁止升级（原先 amount=0 直接免费升级）。
- `license.verify_license`：联网校验时查吊销状态（`session` 可选，离线本地验签不受影响）。
- `artifacts` 签名密钥：不再直接复用 JWT_SECRET，改为 sha256 派生；生产强制 `ARTIFACT_SIGNING_SECRET`。
- 生产闸门新增 `ARTIFACT_SIGNING_SECRET` / `MODEL_KEY_SECRET` 必填；`preflight.sh --gen-secrets` 同步生成。
- 模型配置 SSRF：新增 `validate_upstream_base_url`（HTTPS、禁凭据、DNS 解析后禁内网/回环/链路本地/元数据）；使用服务端 Key 时禁止自定义 base_url。
- 对账 CSV 公式注入转义；provider 枚举约束。
- 非生产才暴露 `/docs`、`/redoc`、`/openapi.json`（可用 `DOCS_ENABLED` 覆盖）；`/metrics` 支持 `METRICS_TOKEN`，生产未配置则 403。
- `payload_middleware`：AAD 的 path?query 在入口固化，避免 trim_query_params 改写后响应解密失败；删除不存在的 `/v1/gateway` 豁免。
