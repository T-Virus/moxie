0结论先行

一句话定位：墨写不是“一键生成爆款”的 AI 写作器，而是把参考作品拆成可审计、可编辑的章节骨架与人物/势力设定，再用结构化改编与签约体检，帮助作者和工作室把“拆书—改编—体检—成稿”做成可重复的本地流水线。

三个判断

判断一

需求真实，但卖点不是“自动写书”

本项目已把拆解、设定、改编、体检、正文、审查、封面、导出串成一条链。单本 15.8 万字的拆解+改编+体检模型成本约 1.4–5.8 元，真正的价值是“少返工、可复用、可交付”。

判断二

最大风险是版权与平台合规

“参考作品→换名→逐章映射”的默认路径，在法律上高度接近改编/实质性相似；平台又在严打 AI 低质内容。产品必须从“去抄袭”叙事转向“合规再创作/编辑辅助”。

判断三

收费必须额度化

建议“订阅底座 + 用量包 + 席位/模块”。个人自带 Key ¥29/月，托管 Key ¥49/月；工作室 ¥199/月起；企业 ¥19,800/年起。无限量套餐会吸引最重的用户，赶走利润。

12 个月中性情景（假设）：M12 付费用户约 1,200，年平均付费 500，混合 ARPU ¥49/月，订阅收入约 ¥29.4 万；加企业与服务合计 ¥36.4 万，固定成本 ¥30 万，净利约 +¥0.9 万，基本打平。保守情景净亏约 ¥24.6 万，乐观情景净利约 ¥65.2 万。
先验证再投入：先卖 20 份 ¥99 的“拆解+签约体检”服务，目标 ≥8 人付费；再找 3 家工作室做 ¥1,999/季度试点，目标 2 家续费。两项都达不到，应转向工作室定制服务/短剧改编，而不是继续堆功能。

4缺陷与风险

这一节必须诚实：有些风险不会“优化掉”，只能“设计掉”。

1. 版权与“实质性相似”

生死线

默认按源章数 1:1 映射，换名+逐章改写仍可能被认定改编。宁波短剧案判赔 25 万元、厦门案判赔 15 万元。缓解：改名“结构化再创作”；权利声明；默认结构迁移而非逐章映射；相似度检测与改编幅度阈值；法务审核；侵权投诉通道。

2. 平台规则与 AI 检测

高

起点 AI 占比 >10% 触发处理；有平台 20% 以下不计、40% 直接拒稿；番茄 2026-07 拒签 16 万本、清理 5.4 万本。缓解：不做“绕过检测”承诺；定位“AI 辅助编辑”；强制人工改写；接入朱雀等检测做风险提示；限制批量起号；优先短剧/海外/自出版。

3. 改编质量与长文一致性

中高

95 章级长文跨批处理；有名字映射兜底、标题去重，但没有语义一致性检查。缓解：20 本黄金评测集；人名/关系/时间线/伏笔自动检查；章节级重生成；人工编辑台；版本对比。

4. 推理模型耗时/成本

中

15.8 万字拆解 28 分钟；8192→32768 重试；推理 token 计入输出。缓解：默认非思考模式；按章并发；断点续跑；成本预估；缓存；BYOK。

5. 单机 exe 难以订阅

高

无账号/License/云端额度/支付；本地 usage.jsonl 可被删改。缓解：账号+设备码登录；Ed25519 签名 License；云端额度账本；7–14 天离线宽限；功能开关；服务端校验。

6. 盗版与 Key 泄露

高

PyInstaller 单文件可解包；Key 在 localStorage；局域网模式无鉴权。缓解：Nuitka/Cython；代码签名；完整性校验；平台 Key 绝不进客户端；网关短时 token；DPAPI/钥匙串；设备绑定；输出水印。

7. 缺乏评测与反馈闭环

中

无黄金集、无盲评、无崩溃上报、无 NPS。缓解：20 本书盲评；可用率/一致性/签约通过率指标；可选匿名遥测；A/B；月度质量报告。

8. UI 学习成本

中

16 个路由、密集表单、专业字段。缓解：3 步新手向导；模板；示例书；短视频教程；默认值；“简版/专业版”切换。

9. 无协作/版本管理

中

本地 JSON；仅章节内历史；无多人角色/评论/审计。缓解：云端同步；版本树/对比/回滚；角色权限；评论；审计日志；自动备份。

10. 售后与退款成本

中

AI 输出不稳定；用户预期高；按本/按章争议。缓解：免费试用+样例报告；明确“不保证签约/过稿”；7 天低用量退款；按成功产出计费；自助文档。

11. 数据丢失/安全

中高

本地文件；MOBIT_HOST=0.0.0.0 无鉴权；无自动备份。缓解：自动备份/回收站；导出；局域网 token；CSRF/限流；云备份可选。

12. 模型供应商依赖

中低

DeepSeek 价格/模型名变动（chat/reasoner 2026-07-24 弃用，映射到 v4-flash 非思考/思考）。缓解：多供应商适配；BYOK；价格监控；失败回退；成本上限。

重点风险：版权是生死线。 当前“参考小说→换名→逐章改编”是经典改编路径，法律上不会因为“换了名字”就安全。必须把“合规”做成产品能力：权利声明、相似度报告、改编幅度检查、AIGC 标注、投诉/下架通道。否则卖得越多，风险越大。
平台风险同样致命： 起点 AI 占比 >10% 触发处理；番茄 2026-07 拒签 16 万本、清理 5.4 万本；星月多部宣传爆款被下架。不要卖“平台检测绕过”，要卖“风险提示 + 人工改写工作流”。

License 与设备绑定（离线 exe 可校验）

流 程

设备码 → 网页登录 → License

exe 启动显示设备码（机器指纹哈希，不含原始硬件信息）；用户在网页/手机登录后输入设备码，服务端返回 License；私钥在服务端，公钥内置 exe。

宽 限 / 吊 销

7–14 天离线，7 天在线校验

最后一次在线校验后 14 天内可用；超过后仅保留阅读/导出，禁用 AI。时钟回拨强制联网；每席位 2 台设备；退款/盗版/共享账号可吊销并降级。

计量与对账

计量事件包含 user_id、book_id、stage（decompose/adapt/expand/review）、chapters、input_chars、output_chars、model、tokens、idempotency_key、signature。幂等键由用户+书+阶段+章节范围+内容哈希生成；只计成功产出；服务端账本为准；与供应商账单、本地用量三方日对账。

模型网关与 Key 安全

平台 Key

绝不下发

客户端拿短期 token 调网关；网关按用户/套餐限流、计费、审计；支持模型白名单与最大 token。

BYOK

本地加密

Windows DPAPI/系统钥匙串；不写日志；不随书稿上传；可直连或走透传网关。

防泄漏

脱敏 + 告警

日志脱敏；禁止 Key 写入 URL/错误上报；XSS 防护；Key 轮换；单用户 token 突增告警。

支付与退款

国内微信/支付宝，海外 Stripe；订单状态机 created → pending → paid → refunding → refunded → closed；回调验签、幂等、日对账；电子发票；个人 7 天内且用量 <20% 可退，年付按未使用月数扣除已用额度；企业 30 天验收；已消耗额度不退。
