# 在线版持续演进 · 第七批（2026-11-17）

本批落地第六批留下的五块候选：**Redis 跨进程去重**、**admin 日志虚拟滚动**、**Sentry 采样后台可视化配置**、**OG 绝对 URL + PWA push**、**出参契约继续扩面**。所有改动仍在工作区未提交。

## 本批完成清单

### 1. 去重升级 Redis（多 worker 精确）

**现状**：第五批的去重是进程内 `_REPORT_CACHE`，多 worker 各记各的，同一错误风暴会被每个进程各转一次。

**改动**：
- `services/sentry.py` 新增 `_dedupe_in_redis()`：用 `SET moxie:sentry:dedupe:<fp> 1 NX EX <window>` 原子占位，多 worker 共享同一把窗口锁；返回 `True` 放行 / `False` 去重 / `None` 表示 Redis 不可用。
- `should_forward()` 新增 `redis_client` / `sample_rate` / `dedupe_window_seconds` 三个可选入参：
  - 传 Redis 客户端时优先走跨进程去重；
  - Redis 异常（连接/超时/命令失败）自动回退进程内缓存，既不放宽成全量也不阻断上报；
  - 采样仍在本地按指纹哈希计算，无跨进程开销。
- `telemetry.py` 把 `request.app.state.redis` 传入；生产是真实 Redis，开发/测试是 fakeredis 或 None。
- 单测 3 个：两个「worker」共享 Redis 时同指纹只放行一次、窗口 key 清除后可重发、Redis 抛异常回退本地。

### 2. 虚拟滚动推广到 admin TaskBoard

**现状**：任务表本身已分页（20/页），无需虚拟化；真正无界的是任务详情弹窗里的执行日志（服务端最多返回 2000 条）。

**改动**：
- 把 client 的 `computeVirtualRange()` 纯函数复制到 admin（`admin/src/utils/virtualList.ts`，6 个单测），保持两个前端项目独立、不引第三方依赖。
- TaskBoard 日志改为定高 26px 行 + 上下 spacer，只渲染视口附近（`overscan=8`）；长消息单行省略，完整内容看 `title` 或「复制日志」（复制走原始 events，不受 DOM 影响）。
- `scrollLogToBottom()` 同步虚拟区间到尾部，避免「滚动到底但只渲染开头几行」。
- 任务表维持分页，避免表格虚拟化破坏 Pager / 点击 / 列宽。

### 3. Sentry 采样率后台可视化配置

**现状**：采样率与去重窗口只能改环境变量，改一次要重启全部 worker。

**改动**：
- 新表 `operational_settings`（key/value JSON/updated_at/updated_by）+ 迁移 `o4e5f6a7b8c9`。
- `services/runtime_config.py`：DB 持久化 + 60 秒进程内 TTL 缓存；范围二次校验；DB 异常回退环境变量默认值，绝不拖挂上报端点。写操作使本进程缓存立即失效。
- 新 API：`GET/PUT /v1/admin/telemetry-config`（读 require_staff、写 require_admin + 审计日志），返回字段含 `source=environment|database` 标明当前生效来源。
- `telemetry.py` 每次上报读取生效配置，显式传入 `should_forward`；多 worker 最多 60 秒内收敛（文档与 UI 均说明）。
- admin 新页面「可观测配置」：采样率 / 去重窗口数字输入、四档快捷预设、生效来源与更新时间，路由 + 导航 + 权限（`telemetry:read/write`）+ 图标齐备。
- DSN 仍只走服务端环境变量，不提供后台修改（避免泄露）。
- 单测 6 个：默认回退、写后缓存失效、越界值回退、DB 故障降级、admin 读写、非 admin 拒绝。

### 4. OG 绝对 URL 与 PWA push

**OG 绝对 URL**：
- `utils/siteUrl.ts::withSiteOrigin()` 纯函数处理域名尾斜杠、路径前导斜杠、未配置回退相对路径（4 个单测）。
- `vite.config.ts` 加 `transformIndexHtml` 插件，把 `{{SITE_URL}}` 占位符替换为构建期 `VITE_SITE_URL`；index.html 的 `og:url` / `og:image` / `twitter:image` 全部走占位符。
- 验证：默认构建输出 `og:image="/icon.svg"`（本地可用）；`VITE_SITE_URL=https://moxie.example.com/` 构建输出绝对 URL 且不产生双斜杠。`.env.example` 补两个新变量说明。

**PWA push 接收端**：
- `public/sw.js` 增加 `push` 与 `notificationclick`：正文/标题截断，通知点击优先聚焦同路径窗口；跳转目标限定同源（`safeNotificationUrl`），跨域与 `javascript:` payload 回退首页。
- `services/push.ts`：能力探测、VAPID base64url → Uint8Array、订阅/退订/查询，失败静默；`safeNotificationPath` 复用同源约束（3 个单测）。
- `components/PushToggle.vue`：登录后顶栏显示「开启/关闭通知」，仅在 SW + PushManager + VAPID 公钥齐备时出现。
- PWA 文本测试扩展 3 个：push 处理、点击同源约束、OG 占位符。

**边界**：本批完成**客户端订阅 + SW 接收 + 点击跳转**；服务端订阅持久化与发送还需 Web Push 发送端（VAPID 私钥 + 订阅表 + pywebpush 或等价实现），未配公钥时功能完全隐藏，不影响现有用户。
