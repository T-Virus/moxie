## 设计取舍与后续
- 云端正文只写黄金三章而非全本：`CLOUD_BODY_CHAPTERS` 限流，避免长篇跑满 `adapt_chapters`
  与 `managed_chars` 额度，全本正文仍是桌面 expand 工序的主场；配置项可按套餐放大。
- 封面技能只产出"方案"，不出图：`generate_cover` 依赖 storage/session，放 API 层更合适，
  技能层保持纯函数便于编排与单测。
- 桌面 / 云端记忆与台账仍是两套：现通过 `options.desktop_ledger` 显式导入打通，
  稳定实体 ID 落盘留待后续批次。
