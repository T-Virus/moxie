## 1. 五个核心卖点（各平台通用，别每次重写）

1. **拆得开**：一本长篇导入后，拆成章节骨架、大纲、角色卡、势力表、道具功法，每一层都能改，不是黑盒吐一段文字。
2. **看得见**：设定图谱把人物关系、剧情脉络、世界观、关键道具连成图，长篇最容易崩的「谁跟谁什么关系」一屏可查。
3. **改得准**：单章体检列出 AI 味、主题偏离、设定一致性、伏笔回收、错别字等项，问题定位到章到段。
4. **拿得走**：产物可导出 JSON / Markdown / HTML，14 个文件（示例数据）都是你自己的，不锁在平台里。
5. **留得住**：客户端 + 安卓端都在本机跑，不上传书稿、不用注册账号、不用买订阅。

> 演示数据（可写进文案，但请标注为示例）：示例作品 395 章 → 177 张角色卡、103 条势力、1882 条人物关系、94 条剧情脉络、86 条世界观设定、35 个关键道具。

## 9. 建议的发布节奏

1. **先知乎**：发方法论长文，建立「有边界、讲实话」的锚点，后续被质疑时可引用。
2. **再小红书**：A 版首发，48 小时后按评论反馈补 B 版方法论。
3. **抖音**：用竖版视频 + 口播，标题用「一本 395 章的书被我拆成了这样」。
4. **闲鱼**：最后发，承接搜索流量，标题堆「离线版 / 大纲拆解 / 安卓 APK」等关键词。
5. 各平台置顶评论统一用同一套 FAQ，减少重复答疑。
