## 本批完成清单

### 1. 质量门禁（原缺口：无 CI、前端零测试）
- 新建 `.github/workflows/ci.yml`，5 个 job：
  - `server-tests`：pytest（排除 live），上传 JUnit XML
  - `migration-check`：临时 SQLite `alembic upgrade head` + `alembic check`
  - `web-apps`：matrix `client` / `admin`，依次 typecheck → lint → test → build
  - `dependency-audit`：`pip-audit --strict` + 三端 `npm audit --omit=dev --audit-level=high`
  - `e2e-desktop`：构建 web/dist + Playwright Chromium 离线冒烟
- 前端引入 Vitest + ESLint（flat config）：
  - client 单测 `src/services/http.test.ts`（4 用例）
  - admin 单测 `src/roles.test.ts`（4 用例，锁住权限矩阵）
  - ESLint 关闭纯排版规则，只保留有效信号（当前 0 error / 少量 warning）

### 2. 迁移漂移（CI 上线前的拦路问题）
- `alembic check` 原报 `model_provider_configs.step_key` 不一致：迁移建的是命名唯一约束 +
  非唯一索引，ORM 用的是 unique 索引。语义相同但形态不同。
- 新增迁移 `m2e3f4a5b6c7_fix_model_provider_configs_unique.py`，用 batch 模式（兼容 SQLite）收敛到模型口径。
- 结果：`alembic check` → `No new upgrade operations detected`。

### 3. 安全边界
- **refresh 会话归属**：`api/auth.py` 的 `/auth/refresh` 增加
  `RefreshSession.account_id == token.sub` 校验，防弱/泄露 JWT 密钥下用自己会话换发他人 token；
  新增回归测试 `test_refresh_rejects_sub_mismatching_session_owner`。
- **IP 口径统一**：`services/audit.py`、`api/billing.py` 改用 `deps.client_ip()`，
  反代（trust_proxy）下审计 IP 与支付回调白名单不再失效。
- **严格 CSP**：`app/main.py` 对普通 API 下发 `default-src 'self' / script-src 'self' /
  object-src 'none'` 等；`/docs`、`/redoc`、`/openapi.json` 用宽松策略兼容 Swagger 内联脚本。
  新增 2 个响应头测试。
- **nginx 加固**：HTTP/HTTPS 两份配置用 `map $uri` 对前端 HTML/静态资源下发严格 CSP、对 API 路径留空
  交给后端；补齐 X-Frame-Options / nosniff / Referrer-Policy / Permissions-Policy / HSTS，
  并在静态资源 location 重复声明（规避 nginx `add_header` 不继承的陷阱）。

### 4. 依赖与容器
- `server/requirements.txt` 每个依赖加主版本上界（`>=x,<next-major`），避免破坏性升级。
- 新增 `server/requirements.lock.txt` 精确版本锁，Dockerfile 优先用 lock 构建（缺失则回退）。
  - 注意：lock 基于本地 Python 3.14 venv，生产镜像是 3.12，建议用 3.12 重新冻结对齐二进制 wheel。
- `server/docker-compose.yml` 所有服务加 `deploy.resources.limits`（CPU / 内存 / pids）。

### 5. 前端体验与性能（顺手做）
- client 路由守卫：`/runs`、`/runs/:id`、`/tools` 未登录跳登录页并带 `next` 回跳；
  `/plans` 保持公开（自身有访客态）。新增 404 页。
- 路由懒加载：首屏 JS chunk 从 **365 KB → 165 KB**，Workspace 等重型视图按需加载。
- 请求层默认 60s 超时（client/admin 两端），上传接口 `timeoutMs: 0` 关闭；超时返回独立错误码。
- admin TS `strict: false → true`，typecheck 仍全过。
