GET STARTED

三步用起来

没有账号、没有激活码，装完就能翻已有数据。

Windows：双击 exe

建议放在一个固定文件夹里，程序会在同目录生成 data/、output/ 等。首次启动若被安全软件拦截，选择「允许」即可（本地服务只监听 127.0.0.1）。

安卓：安装 APK

系统提示「未知来源应用」时按常规放行。首次启动会初始化本地运行环境，稍等片刻进入界面，全程不需要连电脑。

要用 AI 就填自己的 Key

设置 → 模型档案，填端点、模型名和自己的 API Key，再到「工序绑定」指派拆解 / 生成 / 审查各用哪个模型。Key 只存本机，不上传。

FAQ

你大概率会问的几件事

先翻这里，能省掉来回几轮沟通。

真的免费吗？有没有内购或订阅？

安装包免费，没有订阅、没有内购、没有账号。唯一会产生费用的是你自己调用的模型 API —— 那笔钱按用量直接付给模型厂商，与软件无关。

「离线」是不是完全不用联网？

不是。程序和数据都在本机，不联网也能浏览、编辑、查看已有拆解结果、导出文件；只有 AI 拆解 / 生成 / 审查这几道工序需要联网调用模型。所以准确说法是「本地运行、数据不出本机」，而不是「完全断网可用」。

我的书稿会不会被上传？

不会。数据写在本地 data/<书名>/ 下的 JSON 文件里，服务默认只监听 127.0.0.1，API Key 也只存在本机浏览器 / 手机本地，不写服务端、不进任何文件。

模型 Key 怎么弄？

在设置里新建一条模型档案，填服务商端点（如 DeepSeek）、模型名和自己的 Key；需要的话再按工序分别绑定不同模型。不填 Key 也能用本地功能。

能保证过稿、签约，或绕过平台的 AI 检测吗？

不能，也不做这类承诺。它是整理与自检工具，只帮你提前看到结构上的问题；产出请务必人工复核与改写。各平台对 AI 内容有自己的规则，投稿前请以平台当期要求为准。

可以用别人的作品来拆吗？

请只用于自己写的、公版的或已获授权的稿件。「换名 + 逐章改写」在法律上可能被认定为改编 / 实质性相似，风险由使用者自行承担。本工具定位是拆书学习与自有稿件的编辑辅助。

Mac / 苹果手机能用吗？

暂时不行，目前只有 Windows 客户端和安卓安装包（鸿蒙 4.x 可运行）。云同步、多人协作、账号体系也还没有。

能商用？能拿到源码吗？

免费发放的是可使用的安装包，默认按「个人非商业使用」；不含源码、不含商业授权，也不承诺版本更新与售后 SLA。如需商用授权请单独联系。

手机端要连着电脑才能用吗？

不用。APK 里已经带上了运行环境，安装后由手机自己在本机起服务，界面通过本机 WebView 加载，断网也能翻已有的稿子。
