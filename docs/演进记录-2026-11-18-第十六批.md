## 设计取舍与风险

- **稳定 ID 双端镜像而非共享包**：桌面是 PyInstaller 平铺 import（`src/` 直接入 sys.path），云端是 FastAPI 包，跨端 import 会引入打包与部署复杂度。采用纯标准库镜像 + 交叉一致性测试锁定，兼顾离线桌面与云端独立部署。
- **分段调度默认不变**：默认仍是黄金三章，全本靠 options 显式分段，避免影响现有额度口径与前端体验；额度上限由 Settings 硬约束。
- **章级 checkpoint 绑定章号**：默认场景键不变，兼容既有 checkpoint；分段窗口 scale 后不会错跳/重复。
- **日志档位不写库**：灰度命中是高频匿名路径，只落结构化日志与指标，不写 AuditLog，避免放大存储。
- **CSV 不可信输入**：回执 error 来自 webpush 异常文本，统一按公式注入防护处理。
- 所有改动仍在工作区，未提交 git。
