# 小说大纲最全字段总表

- 版本：1.0　生成日期：2026-11-05
- 依据：工作区《迷失蔚蓝》三份大纲产物 + `src/` 中 5 个代码字段定义源（完整清单见 `docs/outline_fields.json` 的 `meta.based_on`）
- 用途：给「完整小说大纲」定义一份可直接落库的字段规范，覆盖用户给出的 7 大模块，并补上工程元数据与交付层。

## 图例

| 状态 | 含义 |
|---|---|
| 已有 | 已有：现存作品数据里已落盘 |
| 代码已定义 | 代码已定义：生成链路已支持，但《迷失蔚蓝》旧产物里没有 |
| 待补值 | 待补值：字段存在但当前数据为空或不完整 |
| 建议新增 | 建议新增：模板要求、当前项目尚未定义 |

落盘位置代号：`D` = decomposed.json；`S` = storymap.json；`C` = chapters.json；`N` = 建议新增结构（尚无落盘位置）。

必填性：`必填` = 缺失即视为大纲不完整；`选填` = 按题材取用；`自动` = 由程序计算或生成，不需人工填写。
